# Portfolio Website (GitHub Pages)

This is a simple multi-page portfolio website built with HTML + CSS.

## Pages
- Home: `index.html`
- About: `about.html`
- Experience: `experience.html`
- Projects: `projects.html`
- Skills: `skills.html`
- Contact: `contact.html`

## How to publish on GitHub Pages
1. Create a repo named: `yourusername.github.io`
2. Upload all files to the root of the repo
3. Go to **Settings → Pages**
4. Source: **Deploy from a branch**
5. Branch: **main** / Folder: **/(root)**

Your site will be available at:
`https://yourusername.github.io`

## Customize
- Replace "Your Name" everywhere
- Update links (LinkedIn, GitHub)
- Add your resume PDF at: `assets/YourName-Resume.pdf` and update filename if needed
